# RTA Arkylizer

An unofficial, fan-made browser extension for **Epic Seven**. It reads the World Arena (RTA) battle
record page you are already on and draws a performance dashboard over it: rank journey, sessions,
hero effectiveness, behaviour tags and a full match browser. The interface ships in **English** and
**Tiếng Việt**.

# Tiếng Việt

## Cài đặt

Tiện ích chưa có trên Chrome Web Store, nên bạn cài trực tiếp từ file vừa tải. Chỉ mất khoảng một phút.

1. **Giải nén** file vừa tải vào một thư mục bạn giữ lâu dài — ví dụ `Documents\rta-arkylizer`.
   Đừng xoá thư mục này về sau, vì trình duyệt sẽ đọc tiện ích trực tiếp từ đó.
2. Mở trang quản lý tiện ích của trình duyệt. Gõ vào thanh địa chỉ rồi bấm Enter:
   - **Chrome, Brave, Opera:** `chrome://extensions`
   - **Edge:** `edge://extensions`
3. Bật **Chế độ dành cho nhà phát triển** (Developer mode):
   - Chrome: công tắc ở góc trên bên phải.
   - Edge: công tắc ở thanh bên trái.
4. Bấm **Tải tiện ích chưa được đóng gói** (Load unpacked), rồi chọn thư mục bạn đã giải nén ở bước 1.
5. Xong. Nếu muốn, bấm biểu tượng mảnh ghép trên thanh công cụ và ghim **RTA Arkylizer** để nút luôn hiện.

## Cách dùng

1. Vào `epic7.onstove.com`, mở **Đấu trường Thế giới** và vào trang **lịch sử đấu**.

3. Muốn đổi ngôn ngữ, bấm nút **EN / VI** ở đầu bảng phân tích.

# English

## Install

The extension isn't on the Chrome Web Store yet, so you install it straight from the file you
downloaded. It takes about a minute.

1. **Unzip** the download into a folder you'll keep — for example `Documents\rta-arkylizer`. Don't
   delete this folder later: the browser reads the extension from it directly.
2. Open your browser's extension page. Type this in the address bar and press Enter:
   - **Chrome, Brave, Opera:** `chrome://extensions`
   - **Edge:** `edge://extensions`
3. Turn on **Developer mode**:
   - Chrome: the switch in the top-right corner.
   - Edge: the switch in the left sidebar.
4. Click **Load unpacked**, then choose the folder you unzipped in step 1.
5. Done. If you like, click the puzzle-piece icon in the toolbar and pin **RTA Arkylizer** so its button is always visible.

## Using it

1. Go to `epic7.onstove.com`, open **World Arena** and go to your **battle record** page.
2. Click the **Analyze** button in the bottom-right corner.
3. To switch language, click the **EN / VI** button at the top of the dashboard.

## Good to know

- It only works on `epic7.onstove.com`.
- Your data is never sent anywhere — everything happens on your own computer.
- Battles you've loaded are saved, so reopening the same player is instant.
- **When there's a new version:** download the new file, unzip it over the old folder, then click **Reload ↻** on the extension card.
- Your browser may show a warning for manually-installed extensions when it starts. That's normal.
- To remove it, click **Remove** on the extension card.
